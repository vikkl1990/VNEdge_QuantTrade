Market → Strategy generates candidates → ML scores probability → Filter + size → Execute → Track → Feed back into dataset

ML answers ONE question: "Given current market conditions, what is the probability this trade will reach TP before SL within X minutes?"

output: prob = model.predict_proba(X)[1] → e.g. 0.72 = 72% chance TP hits before SL
